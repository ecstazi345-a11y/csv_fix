## 5. STATISTICAL METHOD

**Median + MAD modified Z**

`modified Z = 0.6745 × (observed value − median) / MAD`

Recorded properties:

- Symmetric positive / negative deviation handling
- Explicit threshold configuration, authority, and version
- Minimum sample size checked **after** eligibility / dedupe filters
- Source record versions do **not** inflate reference sample
- Current observation excluded from its own reference population
- Future observations excluded
- Code + measurement unit alone **insufficient** for comparability
- Claimed historical sample **not** promoted to verified sample

**Zero dispersion** (reference `[5, 5, 5, 5, 5]`):

| Observed | Status | Delta | Priority |
|----------|--------|------:|----------|
| 5 | `ZERO_DISPERSION` | 0 | INFORMATION |
| 10 | `ZERO_DISPERSION` | +5 | REVIEW_CANDIDATE |

No division by zero. No infinite Z-score. No invented alternative thresholds.
No automatic normal-performance conclusion.
