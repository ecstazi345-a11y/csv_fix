## 4. PROFESSIONAL LAWS

| Law | Meaning |
|-----|---------|
| ANOMALY ≠ ROOT CAUSE | Statistical / descriptive signal ≠ cause |
| CORRELATION ≠ CAUSATION | Association ≠ causal proof |
| TEMPORAL ASSOCIATION ≠ CAUSATION | Time overlap ≠ cause |
| POSSIBLE CAUSE ≠ ESTABLISHED CAUSE | Hypothesis ≠ proven root |
| SUPPORTING CONTEXT ≠ PROVEN CAUSAL RELATIONSHIP | Context helps; does not prove |
| MISSING EVIDENCE ≠ CONTRADICTING EVIDENCE | Absence ≠ refutation |
| CONTRADICTING CLAIM ≠ VERIFIED REFUTATION | Claimed contradiction ≠ verified |
| CONSTRAINT DURATION ≠ PROVEN LOST MAN-HOURS | Delay length ≠ idle proof |
| MULTIPLE HYPOTHESES ≠ MULTIPLE INDEPENDENT LOSSES | No additive causal costing |
| DATA QUALITY PROBLEM ≠ PRODUCTION INEFFICIENCY | Bad comparison ≠ bad crew |
| HIGH ECONOMIC PRIORITY ≠ HIGH CAUSAL CERTAINTY | Urgency ≠ proof |
| SUGGESTED CLARIFICATION ROLE ≠ RESPONSIBLE PARTY | Role hint ≠ blame |

No causal confidence percentages. No opaque root-cause score. No automatic blame.

## 5. ACCEPTED GATE CORRECTIONS

- Project-wide / shift-wide context ≠ object-specific causal evidence
- Other-object and mismatched work-package context blocked
- Occurrence time distinguished from observation, registration, document creation
- Later-created document may describe an earlier event only with applicable temporal context
- Future physical occurrence not automatically treated as cause
- Duplicate source identities do not become independent evidence
- Contradicting context preserved; supporting + contradicting may coexist
- Question deduplication includes operation **and** physical object identity
- `HYPOTHESIS_NOT_SUPPORTED` reserved without automatic refutation mechanism
- No automatic escalation to established causality
